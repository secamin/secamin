## Hi, I'm Noorul Ameen 👋

**Cyber Security Leader** — building and running security programmes end to end, from the SOC floor to the boardroom.

I lead security operations, incident response and identity teams, and I build small, practical tools for the people who defend networks. Everything here comes from problems I met in real investigations.

### 🛠️ Open-source projects

| Project | What it does |
|---|---|
| [**incident-response**](https://github.com/secamin/incident-response) | Lightweight, read-only, dependency-free tools for IR teams. |
| ↳ [**LogReady** – logging gap analysis](https://github.com/secamin/incident-response/tree/main/Tools/log-gap-analysis) | Checks whether a (possibly compromised) Windows or Linux host has the logs you need for an investigation: retention and time frame, MITRE ATT&CK coverage, log tampering, Splunk forwarding, privileged access. Produces an offline HTML report with a 0–100 readiness score. |
| [**detection-engineering**](https://github.com/secamin/detection-engineering) | SIEM detection content as code: Sigma rules mapped to MITRE ATT&CK, with CI validation and conversion to Splunk, Sentinel and Elastic. |
